Files: `vendor.models.json` has 129 records: the 122 from 2026-11-16, all re-checked, plus 7 new. `vendor.scores.json` has 644 self-reported rows. All 644 were carried forward after re-checking their source pages, and none are new.
Scripts: /tmp/vw2/scripts/build_models.py, build_scores.py, diff.py. Downloads: /tmp/vw2/dl, /tmp/vw2/hf, /tmp/vw2/orp.

## Method
- All first-party pages, HF cards and OpenRouter data from the 2026-11-16 run were fetched again today (69 vendor pages, 38 HF repos, 29 OpenRouter endpoint files and the OpenRouter model list).
- Each page's text was diffed line by line against yesterday's copy (/tmp/vw/dl). Pages with identical text were carried forward unchanged except for `retrieved_date`. Every page that changed was read by hand. The changes are listed below.
- `model_as_listed` spellings are unchanged. The first 122 records are in the same order as before.
- OpenRouter rows were rebuilt from today's `api/v1/models` and `/endpoints` data.
- Score rows: all 38 HF READMEs are text-identical to 2026-11-16. The Hydrogen evaluation PDF is byte-identical. The Hydrogen model card changed only in its Safety-report link, and the blog changed only its "Last updated" date. So all 644 rows were carried forward with `retrieved_date` set to 2026-11-17.
