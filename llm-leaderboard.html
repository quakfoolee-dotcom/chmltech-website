    Methodology

    How this database is built and checked.

    Data as of November 11, 2026. 447 benchmark results and 48 list prices, each linked to the page it came from.

    Gather from the source

    Four research agents read each benchmark's own leaderboard or data file and each developer's model and price pages. Every value was copied as published, with the address it came from.

    Use independent results only

    Rankings use results run by the benchmark maintainers. Scores that developers report about their own models are not used, because settings and comparisons vary.

    Match names carefully

    Benchmarks spell model names differently. Names are matched to one entry per model. When a model appears at several reasoning-effort settings, it is ranked on its best setting, which is shown next to the score.

    Red-team the result

    A separate team of agents, which did not collect the data, re-checked values against the source pages and challenged name matches, prices and the frontier. Errors found were fixed or the value was removed.

    Read the numbers with care

    Benchmarks measure narrow tasks under one set of conditions, and results move quickly as models and harnesses change. A model that ranks first here may not be the best on your own documents, processes or data. List prices change and some are introductory; open-weight prices depend on the host. Several well-known boards (SWE-bench, OSWorld, tau-bench, BFCL, METR and Aider) have not yet published results for most of the models listed, so they are not used to rank.
